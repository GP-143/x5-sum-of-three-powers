# x^5 + y^5 + z^5 = n :  ALL integer solutions with -10^7 <= x, y, z <= 10^7,  for every n = 1..300
#
# NO SOLUTIONS OVER Z AT ALL (not just in the box):   n == 4, 5, 6, 7  (mod 11)
#   Proof.  If 11 does not divide x then (x^5)^2 = x^10 == 1 (mod 11) by Fermat, so x^5 == +1 or -1 (mod 11); and 0^5 = 0.
#   Hence x^5 + y^5 + z^5 (mod 11) lies in {-3,...,3} = {0,1,2,3,8,9,10}: the residues 4,5,6,7 never occur.
#   (Check: modulo every prime power q <= 3000, only q = 11, 121, 1331 -- the same obstruction -- fail to be hit by
#    all residues, so there is no further congruence obstruction at those moduli.)
#   In 1..300 this excludes 108 values of n (27 per residue class):
#     n == 4 (mod 11): 4 15 26 37 48 59 70 81 92 103 114 125 136 147 158 169 180 191 202 213 224 235 246 257 268 279 290
#     n == 5 (mod 11): 5 16 27 38 49 60 71 82 93 104 115 126 137 148 159 170 181 192 203 214 225 236 247 258 269 280 291
#     n == 6 (mod 11): 6 17 28 39 50 61 72 83 94 105 116 127 138 149 160 171 182 193 204 215 226 237 248 259 270 281 292
#     n == 7 (mod 11): 7 18 29 40 51 62 73 84 95 106 117 128 139 150 161 172 183 194 205 216 227 238 249 260 271 282 293
#
# Triples below are unordered and written sorted (x <= y <= z); every permutation of a listed triple is also a solution.
#
# SUMMARY  (300 values of n)
#    25  n with at least one solution:  1 2 3 12 30 31 32 33 34 63 64 65 96 179 210 211 212 241 242 243 244 245 274 275 276
#   108  n with no solution over Z (n == 4,5,6,7 mod 11, listed above)
#   167  n with no solution in the box and not excluded by the congruence (solutions outside the box are not ruled out)
#   Solutions: 22 isolated ones, for 22 values of n (largest |variable| is 17, for n = 12; all others have |variable| <= 3),
#              and 3 infinite families, for n = c^5 with c = 1, 2, 3 (below).
#
# INFINITE FAMILIES  (a, -a, c) with c^5 = n, for every integer a, in any of the 3 slots
#   n = 1   : (a, -a, 1)
#   n = 32  : (a, -a, 2)
#   n = 243 : (a, -a, 3)
#   In the box each family has 10,000,001 unordered triples (a = 0..10^7) = 60,000,000 ordered triples (6*10^7).
#   For these three n there are no other solutions.
#
# COVERAGE AND METHOD  (searched for all n = 1..300; for the 108 congruence-excluded n the proof above already settles it)
#   Search program (solve.cpp): modular fifth roots + exact discriminant tests, pruned by sign/size structure.
#     n = 1..99   : all |x|,|y|,|z| <= 9,999,999
#     n = 100..300: all |x|,|y|,|z| <= 10^7
#   Independent exhaustive scan (slab_scan.py, no pruning, shares no code) of the boundary slab max|variable| = 10^7
#   for all n = 1..300: it found only the family members (-10^7, 1, 10^7) for n=1, (-10^7, 2, 10^7) for n=32,
#   (-10^7, 3, 10^7) for n=243.
#   Every listed solution was re-checked with exact big-integer arithmetic.  The search program was cross-checked
#   against brute force (n=1..99 up to R=5000, n=100..200 up to R=12000, n=201..300 up to R=3000) and against
#   unit tests of its fifth-root and 256-bit layers.  Completeness in the box rests on that validation and on the
#   pruning lemmas of the write-up; it is a computation, not a formal proof.  (As the congruence predicts, the
#   search found nothing for the 108 excluded n.)
